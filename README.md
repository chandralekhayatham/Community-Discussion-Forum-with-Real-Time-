# 🚀 Community Discussion Forum with Real-Time Chat

A full-stack web application that allows users to participate in discussions, share ideas, ask questions, and communicate through real-time chat.

## 📌 Features

- 🏠 Home Dashboard
- 💬 Discussion Forum
- 🔍 Discussion Details Page
- 👤 User Login & Registration
- 🔄 Navigation with React Router
- 📱 Responsive User Interface
- 🔥 Real-Time Chat Support (Planned)
- 🗄️ MongoDB Database Integration (Planned)

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router DOM
- HTML5
- CSS3
- JavaScript (ES6)

### Backend
- Node.js
- Express.js

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/community-discussion-forum.git
```

### Navigate to Project

```bash
cd community-discussion-forum
```

### Install Dependencies

```bash
npm install
```

### Start Frontend

```bash
npm start
```

Application will run on:

```text
http://localhost:3000
```
